# ApnaKirana Showcase Landing Page

A modern, responsive showcase landing page for the ApnaKirana instant grocery delivery platform.

## 🔗 Live Application Link
- **Production Store:** [https://apnakirana-vylc.onrender.com](https://apnakirana-vylc.onrender.com)
- **Store Partner Portal:** [https://apnakirana-vylc.onrender.com/login](https://apnakirana-vylc.onrender.com/login)
- **Executive Admin Console:** [https://apnakirana-vylc.onrender.com/admin/login](https://apnakirana-vylc.onrender.com/admin/login)

## 📁 File Structure
- `index.html`: Complete standalone showcase page with Tailwind CSS, hero section, narrative storytelling, interactive features grid, 3-step checkout guide, and prominent CTA buttons that launch the live Render store in a new browser tab.

## 🚀 How to View
Double-click `index.html` in Windows Explorer or open it in any web browser!
